CONTEXT

About the lab.

Cybersecurity, for me, is most useful when I can build something, test it, observe what happens and explain why.

I’m a Computer Science and Engineering student developing toward a career in Security Engineering. My learning has moved from concepts into hands-on labs, CTFs, security tooling, home-lab infrastructure, open-source work and technical write-ups.

I’m particularly interested in the boundary between offensive testing and defensive engineering: understanding how weaknesses are discovered, how controls respond, and how security teams can turn observations into better systems.
