01 BACKGROUND & PHILOSOPHY

Behind the terminal.

My path into security is driven by curiosity for how interconnected systems really work under attack.

Cybersecurity is only as good as what you can build, observe, and defend under realistic stress.

I’m a Computer Science and Engineering student actively preparing for a career in Security Engineering. Rather than treating security as abstract checklists, I focus on the bridge between offensive exploration and defensive engineering: how an exploit gets past filters, how a firewall handles unexpected packet flags, and how security analysts reconstruct the story from telemetry.

My workflow centers around hands-on experimentation. When I learn about a vulnerability class or an architecture pattern, I build the target in an isolated virtual network, simulate the traffic, examine the resulting logs, and document the investigation.
